## 📌 نظرة عامة عن المشروع (Project Overview)

منصة **أكاديمية سَعى (Saay Academy)** هي المنصة التعليمية الرائدة للدروس الخصوصية الفردية التفاعلية (1-on-1)، تربط الطلاب وأولياء الأمور بصفوة **أفضل 5% من المعلمين المعتمدين والمفحوصين** في السعودية، الإمارات، قطر، الكويت، مصر، وكافة الدول العربية لمختلف المناهج التعليمية:
* **المناهج الوطنية والوزارية:** المنهج السعودي (مسارات وقدرات وتحصيلي)، المنهج الإماراتي، المنهج القطري، المنهج المصري واللغات.
* **المناهج الدولية:** المنهج البريطاني (IGCSE & A-Levels)، المنهج الأمريكي (American Diploma, AP & SAT)، والبكالوريا الدولية (IB DP/MYP/PYP).

تم بناء وتطوير صفحة الهبوط بأحدث معايير الويب الفاخرة، مع **استجابة وتوافق مثالي 100% مع جميع شاشات الجوال والهواتف الذكية بدءاً من عرض 370px وحتى الشاشات العريضة**.

---

## 📱 تحسينات تجربة الموبايل (Mobile UX & Responsiveness 370px+)

1. **قائمة التنقل المنسدلة الذكية (Mobile Navbar Drawer):** تثبيت القائمة المنسدلة مباشرة أسفل شريط التنقل بسلاسة وانسيابية مع روابط واضحة وأزرار إجراء سريعة بدون أي اختفاء أو إزاحة.
2. **إلغاء التمرير الأفقي (Zero Horizontal Overflow):** ضبط جميع البطاقات والحاويات والتنبيهات لتكون متناسقة ومتجاوبة داخل حدود الشاشة الصغيرة (370px).
3. **تنسيق بطاقات المعلمين (Mobile Teacher Cards):** عرض الأسعار وأزرار الحجز بشكل متناسق ومريح للمس السريع (`Touch-Friendly Targets`).
4. **شريط الواتساب العائم (Responsive Floating WhatsApp):** تحجيم ذكي للفقاعة الترحيبية وتثبيتها في أقصى يمين الشاشة دون حجب أي محتوى أساسي.
5. **تبويبات رحلة الاستخدام (Mobile Step Tabs):** عرض تبويبات رحلة الطالب والمعلم بشكل متجاور بنظام Grid متجاوب يمنع انقسام الكلمات.
6. **حاسبة الدخل التفاعلية ونماذج الحجز:** تناسق كامل للأزرار والحقول على شاشات الهواتف.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** [Next.js 16 (App Router)](https://nextjs.org/) مع React 19.
* **Language:** TypeScript لضمان الأمان البرمجي ودقة البيانات.
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) بنظام متغيرات التصميم (`CSS Variables`) والتوكنز التفاعلية **بدون أي Hardcoded Colors**.
* **Icons & Micro-animations:** مكتبة الأيقونات المتحركة التفاعلية [AnimateIcons (Lucide Animated Icons)](https://animateicons.in/icons/lucide) و [Motion / Framer Motion](https://motion.dev/).
* **Typography:** خط **Avenir Arabic** المعتمد (`AvenirArabic-Medium.otf`) مع دعم خطوط `Avenir Next Arabic`, `Rubik`, و `Cairo`.
* **Badges & Monograms:** شارات أكاديمية موثقة وشعارات الأحرف الأولى الرسمية للمعلمين بدون أي صور اصطناعية أو ستوك غير واقعي.
* **Interactive Celebrations:** `canvas-confetti` لتأكيد الحجوزات والتفاعل الإيجابي.

## 🚀 التشغيل والتطوير المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي
npm run dev

# بناء المشروع للإنتاج
npm run build
```
